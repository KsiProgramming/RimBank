# Getting help

| You want to… | Go to |
|---|---|
| Ask how something works, or share an idea | [GitHub Discussions](https://github.com/KsiProgramming/RimBank/discussions) |
| Report a bug | [Bug report](https://github.com/KsiProgramming/RimBank/issues/new?template=bug_report.yml) |
| Propose a feature, a roadmap phase or a new BIAN service domain | [Feature or roadmap proposal](https://github.com/KsiProgramming/RimBank/issues/new?template=feature_request.yml) |
| Report a security vulnerability | **Privately**, as described in [SECURITY.md](SECURITY.md). Never in a public issue |
| Contribute code or documentation | [CONTRIBUTING.md](CONTRIBUTING.md), then pick a [good first issue](https://github.com/KsiProgramming/RimBank/labels/good%20first%20issue) |

Before asking, check the [architecture and business documentation](docs/README.md), the [ADRs](docs/adr/) and the [roadmap](specs/roadmap.md). Many "why is it like this?" questions are answered there.

RimBank is maintained by volunteers on a best-effort basis. There is no commercial support and no service-level agreement. RimBank is **not a licensed bank** and provides no regulatory certification.
